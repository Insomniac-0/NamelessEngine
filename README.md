# Nameless Engine

### Build

**NOTE**: only runs on linux atm, have not tried wsl/mingw etc.

To build call build script with optional **target** and optional **params**
```
./build.sh $target $params
```

Example
```
./build.sh week1 debug
```

### Optional Params:
**debug:**
debug flags

**release:**
release flags

**asan:**
address sanitizer
